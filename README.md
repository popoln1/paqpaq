# PAQPAQ

Site PAQPAQ — V0.2.

## Lancer le site en local

Ne pas ouvrir `index.html` directement avec un double-clic : le projet utilise React + Vite et doit être lancé avec le serveur de développement.

### 1. Installer Node.js

Installer une version LTS récente de Node.js.

### 2. Dans le dossier du projet

```bash
npm install
npm run dev
```

Vite affichera une adresse locale, généralement `http://localhost:5173`.

### 3. Pour préparer une version production

```bash
npm run build
npm run preview
```

La prochaine étape du projet est de remplacer les visuels de démonstration par les vrais PAQPAQ, puis de connecter progressivement Shopify.
